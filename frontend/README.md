# Jigsaw Puzzle Frontend

Vite + React + TypeScript + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Structure

- `src/api` — generated/typed API client bindings
- `src/assets` — static assets bundled by Vite
- `src/components/general` — shared, cross-feature components
- `src/components/layout` — page shell/layout components
- `src/components/sections` — feature-specific composed sections
- `src/components/ui` — low-level, reusable UI primitives
- `src/context` — React context providers
- `src/data` — static/local data
- `src/hooks` — custom React hooks
- `src/pages` — route-level page components
- `src/redux` — Redux store, slices
- `src/routes` — route path constants
- `src/services` — API/socket service wrappers
- `src/utils` — shared helpers
- `src/validators` — form/input validation
